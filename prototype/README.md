# Adaptive Mind Simulation — Prototype

The refactored React + Vite implementation of the Adaptive Mind Simulation.

See the [root README](../README.md) for full documentation, usage tips, and design notes.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server with HMR |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build locally |
| `npm run lint` | ESLint |
